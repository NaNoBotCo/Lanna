ที่มา · etymology probable · น่าจะใช่

ยืมมาจากเขมรเก่าสมัยอังกอร์ *គ្លង៑ (*คฺลงฺ), *ឃ្លង៑ (*ฆฺลงฺ); ร่วมเชื้อสายกับคำเมือง ᨣᩖᩬᨦ (คลอง), ᨣᩬᨦ (คอง), อีสาน คลอง, คอง, ลาว ຄອງ (คอง), ไทลื้อ ᦅᦸᧂ (คอ̂ง) Schuessler (2007) นำคำนี้ไปเชื่อมโยงกับซีโน-ทิเบตันดั้งเดิม *kl(j)u(ŋ/k) (“แม่น้ำ; หุบเขา”) ซึ่งเป็นรากของ 江 (OC *kroːŋ, “แม่น้ำ”), 谷 (OC *kloːɡ, “หุบเขา”), ทิเบต ཀླུང (กฺลุง, “แม่น้ำ”), พม่า ချောင်း (ขฺเยาง์:, “ธารน้ำ”) แต่ STEDT ตั้งข้อสังเกตว่าสิ่งนี้ไม่ได้อธิบายถึงพยัญชนะท้ายพยางค์ *-n เป็นศัพท์บัญญัติสำนักงานราชบัณฑิตยสภาของ canal (ภูมิศาสตร์/ทันตแพทยศาสตร์ 13 มี.ค. 2545)

4khlong as an element in place names

ใช้ประกอบชื่อสถานที่
toponymplacestandard · ทั่วไป

Used to build place names. Not listed as a sense by the RID, but 46 of this head's dictionary-attested compounds are place-name definitions (ชื่อตำบล / ชื่ออำเภอ / ชื่อเขต). Heavy in the dictionary (46 place names) but nearly absent from the northern wat registry (2 of 5333), so it builds names somewhere other than the Lanna north. WHERE is not measurable from this project's data, which is northern only.

grew out of sense 1 (canal; waterway) — by metonymy · นามนัย: A place is named for the feature it has — the feature stands in for the location. That is metonymy rather than metaphor: the marsh, the field, the creek is actually there, and the name points at it. probable · น่าจะใช่
