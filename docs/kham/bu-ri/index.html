2bu-ri as an element in place names

ใช้ประกอบชื่อสถานที่
toponymplacestandard · ทั่วไป

Used to build place names. Not listed as a sense by the RID, but 14 of this head's dictionary-attested compounds are place-name definitions (ชื่อตำบล / ชื่ออำเภอ / ชื่อเขต).

grew out of sense 1 (town; city) — by metonymy · นามนัย: A place is named for the feature it has — the feature stands in for the location. That is metonymy rather than metaphor: the marsh, the field, the creek is actually there, and the name points at it. probable · น่าจะใช่
