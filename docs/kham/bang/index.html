12bang as an element in place names

ใช้ประกอบชื่อสถานที่
toponymplacestandard · ทั่วไป

Used to build place names. Not listed as a sense by the RID, but 56 of this head's dictionary-attested compounds are place-name definitions (ชื่อตำบล / ชื่ออำเภอ / ชื่อเขต). Heavy in the dictionary (56 place names) but nearly absent from the northern wat registry (1 of 5333), so it builds names somewhere other than the Lanna north. WHERE is not measurable from this project's data, which is northern only.

grew out of sense 1 (thin; fine; some) — by metonymy · นามนัย: A place is named for the feature it has — the feature stands in for the location. That is metonymy rather than metaphor: the marsh, the field, the creek is actually there, and the name points at it. probable · น่าจะใช่
